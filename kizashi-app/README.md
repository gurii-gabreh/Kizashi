# 結（Yui）

土砂災害の現場で待機する家族・関係者を支援する、Web完結・無料の現場情報共有アプリ。

都知事杯オープンデータ・ハッカソン2026（東京都主催）への提出を目指して開発中。

## これは何か

土砂災害の現場で、待機する家族・関係者への情報伝達の遅れと二次災害リスクを減らし、司令官（現場指揮者）の負担を軽減することを目的としたアプリです。

開発者の親戚が土砂災害に遭い消息不明となり、本人も現場に居合わせ、徹夜で立ち会った実体験が開発の原点になっています。家族・親戚は現場で何も手伝うことができず、ただ救助の知らせを待つしかない苦しさを味わいました。唯一できたのは、建物の間取り・行方不明者の情報・普段の行動パターンなど現場の状況を伝えることだけでしたが、その「伝える」行為も、司令官役の人が家族から直接聞き取らねばならず、指揮・捜索の手を止めることになっていました。しかも聞き取った内容が他の関係者へ伝わる際は人づての伝言に頼らざるを得ず、遅延や伝達ミスも起きやすい状況でした。この「待つことしかできない家族」と「聞き取りで手が止まる現場」の両方の非効率を、あらかじめ情報を整理して共有できる仕組みで解消することを目指します。

主役は「救助する側」ではなく「現場で待機する被災者家族・関係者」です。

## 核心機能

1. **現場ルーム** — 6桁のコードだけで参加できる、ログイン不要の共有スペース。1事案＝1ルーム
2. **危険エリア／待機可能エリアの可視化** — 東京都の土砂災害警戒区域データを地図上に色分け表示
3. **事前問診フォーム** — 行方不明者情報を家族が事前入力し、重複聞き取りを解消（警察届出の標準項目に準拠、暗号化保存）
4. **家の間取り 手書き共有** — 救助隊員に間取りを聞かれる前に、簡易な間取り図を描いて先回りで共有
5. **前兆現象 共有モード** — 国交省公式チェックリストに基づく目撃情報をワンタップで共有
6. **危機感を伝えるUX設計** — 正常性バイアス対策として、具体的な場所・状況を名指しする通知
7. **音声ガイド付き事前問診** — 手が震える等で入力が難しい状況でも、一問一答の音声対話で問診を埋められる（書き起こしはそのまま採用し、AIによる解釈はしない）
8. **傾聴AIチャット「そっと話す」** — 専門家のいない現場で、不安な気持ちに寄り添うAIチャット。助言や予測は一切行わず、深刻な危機のサインは専門の相談窓口に橋渡しする

詳細な要件定義は [`docs/企画整理.md`](docs/企画整理.md) を参照してください。

## 絶対にやらないこと

人命に関わる以下の機能は明確に除外します（詳細は `docs/企画整理.md` セクション5・9）。

- 助かる見込み時間・生存確率の提示（トリアージ・救助優先順位の判断）
- 重機の自動手配
- 指揮官不要の意思決定代替
- 独自の線状降水帯予測アルゴリズム開発

前兆現象は「予測」ではなく「国交省公式チェックリストに基づく目撃情報の共有」として扱い、気象庁データは独自予報として発信せず公式発表の表示・転載にとどめます。事前問診フォームの身体的特徴・病歴・写真等の要配慮個人情報は、暗号化保存・事案終了後の自動削除・現場ルームコードによるアクセス制限を設計に含めます。

## 技術構成（予定）

- **フロントエンド**：HTML/CSS/JavaScript、地図はLeaflet.js＋国土地理院タイル（無料・APIキー不要）
- **バックエンド**：Cloudflare Workers + D1（無料枠）
- **通知**：Web Push通知、または LINE Messaging API（無料枠）
- **東京都データ**：国土数値情報「土砂災害警戒区域データ」（GeoJSON形式）
- **気象庁データ**：防災情報XML（公式発表の表示・転載のみ、独自予報は行わない）

費用は完全無料の範囲（Cloudflare Workers/D1/Pages、LINE Messaging APIの無料枠等）に収める方針です。

詳細は [`docs/企画整理.md`](docs/企画整理.md) セクション7を参照してください。

### src/ の動かし方（ローカル開発）

```bash
cd kizashi-app/src
npm install
cp .dev.vars.example .dev.vars   # INTAKE_ENC_KEY に openssl rand -base64 32 の値を設定
npm run migrate:local
npm run dev
```

ローカルのCloudflare Workers環境（wrangler dev）とローカルD1で完結し、実際のCloudflareアカウントは不要です。本番環境へのデプロイ（`wrangler deploy`）には別途Cloudflareアカウントでの`wrangler login`が必要です。
