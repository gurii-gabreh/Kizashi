# 結（ゆい）利用データの公開性・根拠一覧

都知事杯オープンデータ・ハッカソン2026事務局から2026-08-07に発信された「公表」(お知らせ目的の掲載)と「公開」(明確な利用ルールのあるオープンデータ)の違いに関する注意喚起を受け、結が使用する各データソースについて、二次利用の根拠を整理したもの。審査で利用データの正当性を問われた場合の裏付けとしても使える。

## 総括

都庁の各局が「公表」(お知らせ目的)しているだけの未整理データを、確認なしにそのままアプリへ転載・組み込みしている箇所は無い。東京都に関するデータは主に国土交通省の国土数値情報(利用ルールが明確なオープンデータ)を使用し、東京都独自のサイト(d-keikai・気象庁キキクル)は埋め込みせず外部リンクのみで参照する設計にしている。東京都建設局河川部の土砂災害危険度情報関連データもCC BYで明確に「公開」データと確認済み。

唯一、国土地理院タイルの利用区分(複製/使用のどちらに該当するか)だけ正式な確認が済んでいないため、ハッカソン事務局(#03_事務局への質問)へ確認予定(KIZ-019)。
